Hace poco aprobé la certificación GitHub Actions (GH-200) y quiero compartir cómo me preparé, qué sentí durante el examen y qué representa este logro para mi carrera.

![Certificación GitHub Actions](/img/GitHubActions/actions.png)

## Mi objetivo profesional

Mi objetivo es avanzar hacia un rol de DevOps o Platform Engineer. Esta certificación es un paso importante porque muchas empresas utilizan GitHub no solo para alojar código, sino también para automatizar sus procesos de integración y despliegue continuos (CI/CD). Comprender GitHub Actions es una habilidad valiosa para quien quiera desarrollarse en esta área.

## Experiencia y preparación

He practicado la creación de pipelines CI/CD y el despliegue de infraestructura con Bicep mediante workflows de GitHub Actions. GitHub ha sido mi plataforma principal, y esa práctica hizo una diferencia importante al prepararme para el examen.

Uno de los proyectos que utilicé fue [multiverse-explorer](https://github.com/LuisiitoDev/multiverse-explorer), una aplicación inspirada en Rick y Morty donde configuré workflows para compilar, probar y desplegar. Trabajar en un repositorio real, en lugar de seguir únicamente tutoriales, me ayudó a comprender cómo se relacionan los eventos de activación (*triggers*), los trabajos (*jobs*), los secretos y los despliegues.

Decidí presentar el examen después de completar el [curso de GitHub Actions en Microsoft Learn (GH-200T00)](https://learn.microsoft.com/en-us/training/courses/gh-200t00). Realicé las pruebas de práctica y obtuve buenos resultados. También tomé el [curso de GitHub Actions en Platzi](https://platzi.com/cursos/github-actions/), que me ayudó a reforzar los conceptos desde otra perspectiva. Además, había dedicado aproximadamente un mes a estudiar y practicar intensamente.

## Durante el examen y el resultado

Mientras leía las preguntas, me sentía seguro porque muchas estaban relacionadas con lo que ya había practicado: construir workflows, administrar secretos y configurar jobs y triggers. Algunas preguntas fueron desafiantes, pero en general sentí que me había ido bien. Cuando vi que había aprobado, me emocioné mucho: todo el esfuerzo invertido en estudiar y practicar había dado resultado.

## Qué significa para mi carrera

Este logro es importante porque me permite comprender mejor las responsabilidades técnicas de un DevOps Engineer. También me motiva a profundizar en el lado operativo de DevOps, sin enfocarme exclusivamente en el desarrollo de software.

## Por qué recomiendo presentar este examen

Si trabajás con GitHub o estás pensando en orientarte hacia DevOps, considero que vale la pena. Te impulsa a ir más allá de escribir workflows sencillos y entender conceptos como workflows reutilizables, seguridad, runners autohospedados y la organización de pipelines para proyectos reales.

Estudiar me permitió construir una base mucho más sólida que aprender los conceptos de manera aislada. Además, practicar en un repositorio como [multiverse-explorer](https://github.com/LuisiitoDev/multiverse-explorer) hizo que el aprendizaje fuera más concreto que limitarse a leer documentación.
